# FaceUnlock

Unlock a locked Mac by looking at it.

FaceUnlock is a small menu bar app. It watches the built-in camera while the Mac is locked,
recognises its owner's face, checks that the face is a live person rather than a photo,
and then enters the login password on the lock screen.

Everything runs on the Mac. The app makes no network connections. The login password is kept
encrypted and can only be unsealed with Touch ID.

It is a convenience, not a security upgrade: a 2D webcam cannot match Face ID's depth sensing.
Touch ID and the password always keep working alongside it.

Work in progress.
